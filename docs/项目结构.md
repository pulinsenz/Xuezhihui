## 关键边界说明（写文档 & 面试要讲）

### Java‑backend 职责

1. 用户登录、JWT 鉴权、`@RequireRole` 权限校验；
2. MySQL：用户、知识库 / 文档、收藏 / 成员、对话记录、封禁文件哈希；
3. 接收前端上传文件，做基础解析与文件落盘，调用 python-agent 接口做向量化入库；
4. SSE 接收前端，调用 Python SSE 接口，把 token 流式透传给前端；
5. Feign 调用 Agent 普通接口；长耗时向量化任务写入 Redis List，Python worker 消费，前端轮询；
6. **Python Agent 需要业务数据时，请求 Java 的 `/internal/agent/*` 接口，Java 校验 `AGENT_TOKEN`**。

### python‑agent 职责

1. 只处理 AI 相关逻辑，**不访问 MySQL**；
2. LangGraph 状态图，5 个 Agent 节点流转，支持循环重试；
3. RAG 全套：文档分块、混合检索、重排；
4. 读写 Milvus 向量库；读写 Redis 存放会话、Agent 状态、任务；
5. 提供接口给 Java 调用（`AGENT_TOKEN` 校验）；必要时回调 Java 接口获取业务数据。

### 其他工程要点

- **数据库初始化**：无 Flyway，建表脚本为 `java-backend/sql/init.sql`，由 docker compose 在 MySQL 首次启动时挂载执行；MyBatis-Plus 逻辑删除字段 `isDeleted`。
- **服务间鉴权**：Java ↔ Python 双向校验 `AGENT_TOKEN`；前端 → Java 用 JWT（`Authorization: Bearer <token>`）。
- **文件存储**：`LocalFileStorageService` 落地共享卷 `file-data`（Java 与 Python 容器共享）；预留腾讯云 COS 实现。
- **长任务**：向量化入库为长耗时操作，Java 提交任务到 Redis List，Python `worker/vectorize_worker.py` 消费，前端轮询 `GET /api/task/{id}`。
- **测试**：java 端 JUnit + MockMvc（controller/service），python 端 pytest，前端 Vitest。

## 核心接口清单（便于写接口文档）

### Java 对外（前端调用，前缀 `/api`）

- `POST /auth/register` 注册　`POST /auth/login` 登录　`POST /auth/logout` 登出　`GET /auth/me` 当前用户
- 知识库：`POST /knowledge/create`　`POST /knowledge/update`　`GET /knowledge/list`　`GET /knowledge/public/list`　`GET /knowledge/{id}`　`POST/DELETE /knowledge/{id}/favorite`　`POST /knowledge/{id}/copy`　`POST /knowledge/cover`　`DELETE /knowledge/{id}`
- 成员：`GET/POST/DELETE /knowledge/{id}/members[/{userId}]`
- 文档：`POST /knowledge/{id}/upload`　`GET /knowledge/{id}/docs`　`POST /knowledge/{id}/docs/batch-vectorize|batch-delete|batch-remove-vector`　`DELETE /knowledge/{id}/docs/{docId}`　`POST .../{docId}/revectorize|remove-vector|restore`　`DELETE .../{docId}/purge`
- 对话：`POST /chat`　`GET /chat/stream?sessionId=`　`GET /chat/sessions`　`GET /chat/sessions/{sessionId}/history`　`DELETE /chat/sessions/{sessionId}`
- 任务 / 设置：`GET /task/{id}`　`GET /settings`　`PUT /settings/vectorize-default`　`PUT /settings/collapse-refs`
- 管理员：`GET /admin/user/list`　`PUT /admin/user/{id}/role`　`DELETE|PUT /admin/user/{id}[/restore]`　`GET /admin/knowledge/list`　`GET /admin/knowledge/{id}/docs`　`DELETE|PUT /admin/knowledge/{id}[/restore]`　`DELETE/PUT/POST/POST /admin/knowledge/{id}/docs/{docId}[/restore|revectorize|remove-vector]`　批量操作接口

### Python Agent 接口（Java 调用，携带 `AGENT_TOKEN`）

- `POST /api/agent/chat` 普通对话
- `GET /api/agent/stream?session_id=` SSE 流式 Agent
- `POST /api/knowledge/vectorize` 文档向量化入库
- `POST /api/knowledge/delete` 删除文档向量

### Python 回调 Java（Java 校验 `AGENT_TOKEN`，前缀 `/api/internal/agent`）

- `GET /user-stats` 获取业务数据
- `POST /chat-save` 回写对话（回答 / 思考 / 参考文献）
- `POST /vector-callback` 向量化结果回调
